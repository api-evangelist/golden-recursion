# Golden Recursion (Golden)

> Golden Recursion Inc. builds Golden — a self-constructing, AI-powered knowledge graph of millions of connected entities (companies, people, VCs, products) with structured, cited data. The Golden API v2 gives read-only, programmatic access to the same data that powers the Golden Query Tool, filtered, sorted and paginated, authenticated with an apikey header. Generated by the API Evangelist enrichment pipeline.

## APIs
- [Golden API v2 (Public)](https://golden.com/): Read entities, saved-query results, and the entity-type/predicate schema. Base path /api/v2/public, apikey header auth.

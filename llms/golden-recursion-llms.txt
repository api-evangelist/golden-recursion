# Golden Recursion (Golden)

> Golden Recursion Inc. built Golden — a self-constructing, AI-powered knowledge graph of millions of connected entities (companies, people, VCs, products) with structured, cited data. The Golden API v2 gives read-only, programmatic access to the same data that powers the Golden Query Tool, filtered, sorted and paginated, authenticated with an `apikey` header. Golden was acquired by ComplyAdvantage on 2024-04-24; golden.com now serves an acquisition notice, but the API and its reference documentation remain live. Generated by the API Evangelist enrichment pipeline; verified 2026-08-14.

## Status
- Company acquired by [ComplyAdvantage](https://complyadvantage.com/press-media/complyadvantage-acquires-golden/) (announced 2024-04-24). Product surface is in wind-down.
- API v2 still answers: an anonymous `GET https://golden.com/api/v2/public/schema/entityTypes/` returned HTTP 403 with the documented JSON error envelope on 2026-08-14.
- The API reference at docs.golden.com is a static Scalar snapshot; its own source notes the upstream spec server ("pathfinder") was decommissioned 2026-07-02.
- No status page, no changelog, no roadmap, no deprecation policy is published.

## APIs
- [Golden API v2 (Public)](https://golden.com/api/v2/public): Read entities, saved-query results, and the entity-type/predicate schema. 8 read-only GET operations. `apikey` request header.

## SDKs
- [godel (Python)](https://github.com/goldenrecursion/godel): Golden's official open-source Python SDK — but for the golden.xyz **protocol** GraphQL API, not this REST API. Last release v0.8.0 (2023-03-31); PyPI holds the name with zero published files, so `pip install godel` does not resolve; golden.xyz no longer resolves.
- [goldnlp (Python)](https://github.com/goldenrecursion/goldnlp): NLP/NLU framework for the Golden Knowledge Graph Protocol. Last release v0.0.2 (2022-11-08); same PyPI situation.
- [GitHub org](https://github.com/goldenrecursion)
- The REST Golden API v2 ships **no** client library — call it directly over HTTPS.
